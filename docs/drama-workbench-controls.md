# 剧本工作台操作与回执

## 归档、恢复和删除作品

在「作品库 → 创作中」点击作品卡片的「归档」。作品移到「已归档」，画布、资料、稿件版本、批注和总编对话都保留。需要继续创作或审稿时，在「已归档」点击「恢复」，再从「创作中」打开原作品。已有链接仍指向同一个作品。

任务正在排队、执行、暂停或停止，以及节点正在检查输入输出时，归档会说明原因并保留当前进度。等任务结束后再归档，也可以先在工作流中停止相应轮次。仅等待人工审稿和上游放行的作品可以归档，恢复后可继续审同一版稿件。

「永久删除」位于「已归档」作品卡片上。确认窗口会显示作品名。确认后，工作台清理该作品的资料和上传原件、画布与执行历史、稿件及批注、审稿与导出记录、专属会话和记忆。其他作品及共享的模板、Agent 和 Skill 继续可用。下载到电脑的文档和独立备份由用户保管。若清理中断，回到「已归档」点「重试删除」。

## 配置 Agent 与作品总编

在「Agent」里先创建直接执行剧本工作的 Worker，再创建 Manager 和 Orchestrator。每份配置均选择 DSH 模型，可以填写职责、推理等级并绑定 Skill。在协调角色的「允许委派的 Agent」勾选实际可用的下属。未授权下属时仍可审核输入并给出结论。公开网络在 Worker 的权限中开启，搜索来源在「连接」页管理。编辑已保存的 Agent 会创建新版本，其角色固定。停用配置后，已有执行的配置快照仍可查看。

新建作品时可选择总编。在作品页点「作品总编」可改绑。存在唯一可用总编时可直接采用该配置。有多个候选时应指定负责总编。使用其他总编的新对话和历史会话均保留在各自作品中。

「Agent → 运行规则」展示工作台使用的角色协议、作品内总编可用的管理操作、节点输出协议、独立校验指令、工具、一次可拆分的子任务数和校验回执长度。节点面板的「本轮实际配置」对应这次执行保存的版本。

## 编辑画布与模板版本

在画布空白处点右键，就地添加节点。在节点上点右键，可以打开节点设置或删除节点。直接拖动节点调整位置，从节点的连接点拖至目标节点可以连线。未分配 Agent 的节点可留在草稿里，发布前需选定负责的 Agent。

改动自动保存在工作台。图下方列出节点、配置和连线相对生效版本的变化。刷新页面或重新打开原画布，可以继续这份草稿。点击图右上角的保存按钮后改动才会生效。已有运行继续使用启动时的画布。编辑期间可查看生效画布、继续审稿，再返回草稿。

模板在每次发布时生成一个固定版本。「模板库 → 版本历史」可查看各版名称、说明和节点数。从所选版本编辑，打开的就是那一版的节点图和配置。保存后它成为模板的最新版本。已建作品保留当初复制的独立画布。若另一窗口已有草稿，确认替换前会保留原草稿。

## 运行、审稿与批注

添加节点时可选三种角色。填入该节点的默认执行指令、输入输出检查与放行条件。Manager 和 Orchestrator 可按指令拆分给授权下属、要求退修、审核或验收。Worker 提交作品内容。选中运行过的节点可查看各子任务、执行尝试、结果与错误，并单独重试允许重试的子任务。「历史 → 执行与审稿记录」列出本轮用户可见的投递、模型回复、工具调用与回执、人工审稿和稿件版本。

输入页可恢复节点的默认执行指令。保存的执行指令及资料版本用于后续运行，已开始的执行保留自己的输入。申请暂停后在安全点生效，重跑会另起一轮。检查不通过或模型无法判定时可以查看原因。配置人工批准的节点必须通过人工审核，已放行的确切稿件版本会提供给下游。

在节点成果阅读页，点「关联分集或场次」可用这一版成果新建分集正文，或链接已有分集的确切版本。双向链接保留来源。

在「分集」展开一集，点「打开正文与批注」；也可从节点审稿、历史或「成果导出」打开成果与批注。选中原文再点击「批注选中文字」，选择「仅保存批注」或「提交总编修订」。保存后可从同一条批注提交总编，包括旧版工作台保存的分集批注。每条批注关联原文版本、字符选区和至多一项修订任务。原文可打开总编委派任务，总编对话中的任务也能返回原文。

修订任务完成后，在原批注点「审阅修订」，对照选区和候选替换文本，可再编辑后采纳或放弃。采纳分集修订会生成新版本，选区外的正文保持原样。采纳已经放行的节点成果修订会新增一轮，执行对应输出检查与放行条件。旧轮和已交接的成果继续保留。新一轮取消或失败且没有产稿时，仍能继续修订上次实际提交的稿件。源稿在此期间发生更新时，点「对照最新稿 → 在最新稿重新定位」，在新稿上重新选区。新批注保留返回原批注的入口。

## 从作品对话管理画布

使用「总编对话 → 对话与管理工作流」，例如“用分集模板建立一条创作流程”“这次运行在等哪个节点”。总编的画布管理范围限于当前作品。「追加独立任务」创建单独的创作委派。对话窗口自动显示消息、任务状态及工作流操作回执。

创建或修改画布时，总编提交草案。点击回执中的「打开草案」可在同一个画布编辑器调整节点、连线和配置，点击「保存总编草案」后更新工作流。保存时核对底稿版本，遇到同时修改时保留草案并提示冲突。新增角色建议需要人工打开「配置此 Agent」，指定模型和可委派对象并保存。

执行和停止按对应的画布版本、节点和运行轮处理。回执的「查看运行」可检查各节点状态及阻塞原因；也可在此停止指定轮次。在其他窗口调整画布，不会覆盖本窗口未保存的草案。

## 隔离验收

`tests/drama-annotations.test.ts` 验证重复提交和派发、旧版批注派工、来源版本冲突、修订后选区以外的正文、已放行成果修订及旧稿交接。构建后运行 `node --test dist/tests/drama-annotations.test.js`。

`scripts/drama-ui-smoke.mjs` 从 Chrome 验证三种角色、执行与审核、批注与稿件版本、导出及模板复用。`scripts/drama-editor-ui-smoke.mjs` 使用隔离的本机模型协议测试端点验证总编对话、真实工具回执、画布草案编辑、运行、停止与建议 Agent 的人工授权。两者均可用 `STUDIO_PLAYWRIGHT_MODULE` 与 `STUDIO_CHROME_BIN` 指定宿主已安装的浏览器组件。
