# 组件与数据

工作台作为独立的 Node.js 进程运行。浏览器通过同源 HTTP 请求操作项目，模型调用与 Agent 会话复用 DSH 公开接口。从源码运行和容器运行使用相同的作品数据格式。

| 组件 | 职责 |
| --- | --- |
| Web 界面与作品接口 | 作品归档、Agent 和 Skill 配置、画布草稿、模板版本、分集、批注、审核和导出 |
| 工作流与任务调度 | 检查无环依赖和输入、持久化运行、派发任务、恢复中断、收集子稿并处理放行条件 |
| DSH 运行时 | 按角色创建会话，解析模型与推理等级，调用获得授权的工具，记录消息与工具交互 |
| 记忆与材料 | SQLite 保存长期方法、会话级记录和恢复检查点，按 Agent 身份与层级限制可读范围。资料原件按作品存放，读取时根据节点绑定的版本取用 |

## 版本与交接

模板的新版本只影响后续选用该版本的画布。节点尝试锁定本轮的执行指令、Agent、资料、上游稿件和权限记录。产稿、规则判断、退修意见和人工审批关联到具体版本。有人工审核要求时，下游在通过后才能消费该版本。重跑保留旧运行和成果。批注采纳也生成新版本，可以追溯到原文选区。

## 数据目录

SQLite 主库为 `studio.sqlite`。作品资料原件按作品和内容散列存储在 `drama-blobs/`。运行时还会在同一数据目录保存会话记录及相关附件。迁移或恢复时应复制完整数据目录。模型端点与凭据从所指定的 DSH 配置中读取。在 Docker 部署中，独立的只读模型配置服务通过 Unix socket 提供限定文件的访问。

本地 Worker 使用容器执行时要求明确配置可信镜像和可用的 Docker 环境。公开网络调研使用独立的 Agent 权限。数据库中的授权记录以及当次任务绑定的权限共同决定可执行的工具。
